# Nezif Al-Oromi — Developer Portfolio

Personal portfolio website hosted on GitHub Pages.

Live at: [https://nezifaloromi1.github.io](https://nezifaloromi1.github.io)

## Sections

- **Hero** — Introduction, name, tech badges
- **About** — Background, learning, location
- **Projects** — Featured projects (Truzlink, Hadith-App, AI Note)
- **Skills** — Tech stack categorized
- **Stats** — Dynamic GitHub statistics
- **Contact** — Email, GitHub, LinkedIn, Portfolio links
- **Footer** — Social links and tagline

## Deployment

This site is automatically deployed via GitHub Pages from the `docs/` folder of this repository.

## Technologies

- HTML5
- CSS3 (with CSS Variables and Grid/Flexbox)
- Vanilla JavaScript
- Font Awesome icons
- Google Fonts (Inter)

## Features

- Fully responsive design
- Dark theme by default
- Smooth scroll animations
- Animated stat counters
- Mobile hamburger navigation
- Dynamic GitHub API stats
